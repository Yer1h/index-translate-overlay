# Index-Translate Overlay

Локальный переводчик-оверлей для Windows на модели [bilibili/Index-Translate](https://github.com/bilibili/Index-Translate) (2B, GGUF, llama.cpp). Всё работает офлайн на GPU — RTX 4050 6 ГБ хватает с запасом (~2 ГБ VRAM).

Четыре режима:

- **выделенный текст** — книги, браузер, переписка (эмуляция Ctrl+C);
- **область экрана** — игры, картинки, скриншоты (нативный vision-перевод модели, без OCR);
- **буфер обмена** — что угодно скопированное;
- **автоперевод ввода** — печатаешь по-русски в любом поле, сделал паузу — текст сам переводится на нужный язык и вставляется в поле.

## Установка (Windows, NVIDIA GPU)

```
git clone https://github.com/Yer1h/index-translate-overlay
cd index-translate-overlay
setup.bat     # venv + llama.cpp + модель (~2.5 ГБ загрузки)
start.bat     # запуск: трей, без консоли
```

Нужен Python 3.12 (`py -3.12`), curl и tar (есть в Windows 10+ из коробки).

## Запуск

```
start.bat          # обычный запуск: трей, без консоли
start-debug.bat    # с консолью для отладки (логи: logs/app.log, logs/server.log)
```

Приложение сидит в трее (иконка «文») и само поднимает `llama-server` на `127.0.0.1:8080`.

## Горячие клавиши (по умолчанию)

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+T` | перевести выделенный текст |
| `Ctrl+Alt+G` | выделить область экрана и перевести текст на ней |
| `Ctrl+Alt+C` | перевести буфер обмена |
| `Ctrl+Alt+I` | вкл/выкл автоперевод ввода |

Карточка с переводом появляется у курсора (или под выделенной областью), текст стримится по мере генерации. Кнопки: «Копировать», «📌 закрепить», «✕». Клик мимо — закрыть. **Карточку можно перетаскивать** за полоску с точками сверху (двойной клик по полоске — закрепить).

## Автоперевод ввода (`Ctrl+Alt+I`)

Режим для переписки: включаешь (в трее появится синяя плашка «⌨ RU → English»), печатаешь в любом поле ввода по-русски, делаешь паузу ~2.5 с — всё написанное переводится на выбранный язык и вставляется в поле обратно. Работает в мессенджерах, браузере, играх с обычным чатом.

- Язык перевода ввода и длину паузы — в настройках или в трее («Язык ввода»).
- Клик по плашке — выключить режим.
- Осторожно в терминалах/IDE: Ctrl+A/C/V могут сделать не то (если копирование не удалось, режим ничего не вставляет — безопасный выход).

## Состав

```
app/        код приложения (PySide6)
bin/        llama.cpp (ставится setup.bat, в git не входит)
models/     GGUF-модели (ставится setup.bat, в git не входит)
tests/      живые e2e-тесты (нужен запущенный оверлей)
bench.py    тест скорости/качества: .venv\Scripts\python.exe bench.py
setup.bat   первичная установка (окружение + бинарники + модель)
config.json настройки (создаётся при первом запуске)
```

## Настройки (трей → Настройки)

- **Язык перевода** — быстрое переключение также из трей-меню.
- **Движок** — «Локально · 2B» (оффлайн) или «Онлайн API · 35B» — бесплатный публичный API Bilibili (нужен интернет; качество выше, но всё уходит на их сервер).
- **Модель/квант** — можно положить в `models/` другой GGUF (например Q8_0 поточнее или Q4_K_M побыстрее) и выбрать его.
- **Контекст** — 6144 по умолчанию; для очень длинных абзацев можно поднять до 8192 (VRAM хватит).

## Замерено на RTX 4050 Laptop (6 ГБ) — Q6_K

| Режим | Время | Пример |
|---|---|---|
| Текст en/ja/zh → ru | 330–480 мс | «Собрание переносится на пятницу в 15:00…» |
| Картинка/скриншот → ru (vision) | ~700 мс | «Ваша подписка истекает через 3 дня…» |
| Первый символ (стриминг) | ~400 мс | текст виден сразу, дописывается на глазах |

VRAM под модель+vision+кэш: ~2 ГБ (запас для игры остаётся). Бенчмарк: `.venv\Scripts\python.exe bench.py`.

## Известные ограничения

- Выделение текста не работает в приложениях, блокирующих синтетический ввод (некоторые игры с античитом) — используй `Ctrl+Alt+G`.
- Горячие клавиши не сработают в игре, запущенной от администратора (сам оверлей тогда тоже нужно запустить от администратора).
- Эксклюзивный полноэкранный режим игры перекрывает оверлей — переключи игру в «окно без рамки» (borderless).
